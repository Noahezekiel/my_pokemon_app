# Welcome to My Pokemon App 
***

## Task
Create a modern, responsive web application that functions like a Pokédex. The app must fetch real Pokémon data from the PokéAPI, display it in a searchable, lazy-loading list, and show detailed information on a separate page. The challenge lies in using real-time API requests, infinite scroll, filtering, and clean component-based architecture using React.

## Description
This project is a React-based Pokédex application that uses the PokéAPI to display a list of Pokémon. Users can:
- Scroll through Pokémon with infinite lazy loading.
- Search for specific Pokémon by name.
- Click on a Pokémon to view detailed stats, types, height, and weight.
- Experience a mobile-friendly, modern design inspired by the official Pokédex style.

The app uses:
- React Router for navigation
- Axios for API requests
- IntersectionObserver for lazy loading
- CSS modules for styling

## Installation
To install and run the project locally:

git clone https://github.com/your-username/my-pokemon-app.git
cd my-pokemon-app
npm install
npm start


## Usage
To start the application locally: npm start
Then, open your browser and visit: http://localhost:3000
